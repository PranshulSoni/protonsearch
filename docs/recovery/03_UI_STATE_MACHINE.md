# UI contract

Hidden → summon → compact Search. Blank input, focus and Search-dot click retain pill geometry. Nonblank input → bounded results. Clear → compact. Feature dots → selected card. Escape → detail parent or compact Search, then hidden. Summon/Escape invalidate delayed card transitions. Explicit dots retain latest intent.

Existing islandDims reference geometry is reused. Width/height native morph coordination and measured motion fidelity remain open; a passing state test is not an animation benchmark.
