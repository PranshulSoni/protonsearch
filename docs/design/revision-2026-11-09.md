# Dock design revision — 2026-11-09

Scope: `dock-editable.html` (the canonical design file), revised in full. Branch `dock`.
Brief: [dock-design-brief-v2.md](./dock-design-brief-v2.md). Audit: [design-slop-audit-2026-11-09.md](./design-slop-audit-2026-11-09.md).

## Result in one line

The file went from a decoration-led prototype (2,945 CSS lines, 49 colours, 21 gradients,
28 shadows, emoji, no responsive or reduced-motion support) to a content-led dock:
1,799 CSS lines on one role palette, 0 gradients, 7 shadow uses, one 63-drawing icon set,
5 breakpoints, a complete reduced-motion path, and 37 `:focus-visible` rules.

## What was rebuilt

1. **Stylesheet (full replacement).** Tokens → base → stage → shelf → rail → tiles →
   widget anatomy → states → popovers → customizer → search → toast → browser surfaces →
   responsive → reduced motion. Neutral glass only; no category tints; rest is no surface;
   hover/press/active/off/disabled/drag/focus are one matrix.
2. **Icon system.** 63 drawings on one 24×24 stroke grid (1.6 stroke, round caps), replacing
   37 inline SVGs + 51 JS SVG strings + 2 emoji. Solid Windows 11 flag is the only filled
   brand mark; every icon-only control has an accessible name; real app marks are neutral
   placeholders (the native extractor supplies real icons at DPR).
3. **Widget content and honesty.** Weather emoji became words; fabricated telemetry claims
   removed; battery "simulation" became a labelled preview; analog clock hands now move and
   the date/zone are real; calendar week is generated for the current week; Claude/Codex
   lost their marketing copy, fake "Connected" badges and unread credential fields; every
   sample widget is flagged `data-demo` and disclosed in the customizer.
4. **Behaviour.** Inline `onclick`/`oninput` removed (listeners live in the script); scope
   pills became real buttons and are wired; the toast moved out of the hidden search modal to
   a `role="status" aria-live="polite"` live region; keyboard focus is restored across dock
   re-renders; the open tile gets `is-active`.
5. **Motion.** Tokenised durations/easings; one authored entrance; popovers 180/120ms;
   magnification kept at 0.22 / 86px (per CLAUDE.md "motion preserved"); one sanctioned loop
   (equalizer, paused when not playing, frozen under reduced motion); data geometry never
   animates; `prefers-reduced-motion` collapses and disables everything.
6. **Layout/theme.** Four responsive bands (1024/1280/1440/1920), Dark/Light/Glass on one role
   set, themed selection/caret/scrollbars, no catalogue-wide shadows or glows.

## Decisions taken (and why)

* **Magnification kept** at 0.22 / 86px. The stylesheet agent proposed 0 to protect icon
  crispness; CLAUDE.md says removing existing motion is a regression, and vector glyphs stay
  crisp. The tile transform is untransitioned so it tracks the cursor.
* **One loop kept**: the equalizer. It is a state indicator for playback; it is paused when
  not playing and frozen under reduced motion. No other infinite animation remains.
* **Toast moved** to `<body>`; inside the closed search modal it was invisible (every dock
  toast today was dead). It now has a live region.
* **Sample data is disclosed**, not deleted: preview widgets carry `data-demo`, the customizer
  shows a "Preview data" chip, and the popovers say "Preview data".
* **Brand marks are not redrawn**: Spotify/Claude/Codex/Slack/Figma/NVIDIA/Steam/… become
  neutral function glyphs in the design; the native app supplies real extracted icons at DPR.

## Not verified / open

* No claim of pixel-identical parity with any earlier design or with docktor. This is a new
  intentional design direction; compare the screenshots, not a diff.
* Native app untouched: this revision is the HTML authority only. The Tauri/React app still
  renders its interim dock and is unaffected until it is ported from this file.
* Native DPI, real data providers, screen-reader pass and physical 125/150% rendering are not
  checked here.
* **Pinning is deferred.** `docs/design/dock-editable.2126c49.html` remains the pinned copy;
  `scripts/html-pin.mjs` still passes and now reports drift. After the user approves this
  revision, create a new snapshot and update the hash in the script.
