Tooling installed

rust-skills is installed at .agents/skills/rust-skills, pinned to fd2a861ab0406a4ac536a55274d14ea6fd1ca9c9 from leonardomso/rust-skills. License: MIT, preserved with the package. It covers Rust ownership, errors, async/concurrency, unsafe/FFI, testing and API design. It will be available to Codex on the next turn. [S16]

The installer copied the upstream skill bundle, including its optional validation fixtures. Those are imported reference/tooling assets, not Proton runtime implementation, and were not run. Review relevant rules selectively; do not blindly apply upstream version claims, broad optimization advice or Miri requirements to unsupported Windows FFI. Local repo/user instructions retain precedence.

Existing frontend-design, writing-plans, brainstorming and verification skills were used for this planning artifact. Research used built-in web tools after the local Firecrawl CLI was found unavailable. No additional MCP server or runtime service was installed: available GitHub, filesystem and web capabilities already cover the planning need. A privileged desktop-control MCP is not a prerequisite for implementing a dock.

Relevant prior art

Search launchers are one comparison category. Desktop-environment and widget hosts are the closer category for 2.0. Study Seelen UI for Windows dock integration and its Rust/Tauri architecture, Zebar for widget/pop-up composition, and YASB for system-provider/configuration breadth. Their existence is useful evidence that several approaches are possible, not evidence that Proton meets its budgets. Proton's proposed distinction is responsive information widgets in one dock combined with its existing content search and explicit agent workflows. Validate that combination with users; do not claim the market has no similar product. Review licenses before any reuse; no implementation was copied. [S23] [S24] [S25]

What this pass deliberately does not claim

No working Windows taskbar replacement, measured 2.0 performance, proven sandbox, complete tray compatibility, chosen final renderer, legally cleared SDK or running local models. The interactive concept uses sample data. The value of this deliverable is an executable sequence of decisions and acceptance gates, not a simulated claim that the platform is already built.
