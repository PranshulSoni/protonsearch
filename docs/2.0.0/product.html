01 / PRODUCT & EXPERIENCE

The dock is the product.

An adaptable workspace that earns its place on screen through useful information and immediate actions.

Reference-directed compositionOne continuous dock contains apps, information and system widgets. The updated mockup follows the user-supplied HTML, including its adaptive width, gallery and layout editor. The separate status capsule is withdrawn.

What we understand

Proton becomes the user's main desktop hub. Its dock contains live, resizable widgets rather than only application icons. Clicking weather opens its detailed forecast; clicking Search opens the existing Proton Search experience; clicking Start opens our own app drawer. Profiles replace the dock composition for work, home or presenting.

“Everything is a widget” is a presentation and customization promise. Recovery, capability checks, persistence and Windows integration remain platform services. Hundreds of widgets describe the eventual ecosystem, not the first release.

Glance

Understand status without opening a window: weather, next meeting, battery, volume and agent progress.

Act

Click once to open the right panel, launch an app, switch windows or adjust a control.

Compose

Choose widgets, sizes, order, edge, appearance and profiles. Hide anything visible without losing recovery access.

Size expresses information

Use device-independent units. Reference baseline: an 82 DIP dock with a 66 DIP content band. Each widget has its own bounded width, and its contents adapt as that width changes. Compact/standard/rich can be useful presets over continuous sizing. Profiles store height, order, visibility, widths and appearance. All widgets remain inside one outer shell; on narrow canvases its single track stays horizontally navigable.

Three initial profiles

Work

Start, Search, Agents, pinned developer apps, files, weather, audio, battery, tray access, clock.

Home

Search, apps, games/media, richer weather, files, volume, battery and clock.

Presentation

Minimal apps, clock, volume and battery. Hide private filenames, message previews and agent details. Background jobs keep their existing grants.

Defaults and boundaries

  • Local-first storage; weather and optional agent providers disclose network usage. Local agent orchestration does not imply a local language model.
  • Default monitor is the primary monitor. A dock may be enabled per display; disconnected display layouts remain saved.
  • Always reachable settings and restore commands through a host-owned shortcut. Bare Windows-key takeover is optional and postponed.
  • Clock/system status degrade gracefully. Missing battery hardware shows “Desktop power”; offline weather shows last update age.
  • Respect reduced motion, high contrast, keyboard navigation, Narrator, text scaling, right-to-left and localization. Rich data cannot be the only way to perform an action.
