# Mockup artwork

All SVG files in this directory are original artwork created for this Proton HTML study.
Files, Browser, Code editor and Terminal are illustrative application icons, not extracted
third-party app trademarks or representations of the user's installed applications.
The abstract wallpaper is an original vector illustration. No external assets, fonts,
CDNs, Windows icons or runtime dependencies are used.

The artwork is covered by this repository's MIT license.

The interactive widget revision also defines original inline SVG glyphs in
`../widget-library.js`. Its Notes, Browser and Code monograms represent fictional
sample apps. The music cover is CSS gradient/line artwork in `../widget-polish.css`;
the mockup plays no audio stream and uses no third-party album artwork. No generated
bitmap assets were needed for these minimal vector and CSS components.
