Tools, context, and actions in one quiet place.

Click a widget to explore.
01

One widget language

Start, search, running apps, sound, weather, battery and time all share sizing, configuration, lifecycle and actions.

02

Native where it matters

Rust owns Windows integration and search. A native dock is the first candidate, with an explicit renderer comparison gate.

03

Recoverable by design

Explorer stays running. Taskbar hiding is an opt-in compatibility mode after recovery, tray access and monitor behavior are proven.

The recommendation

Build a Windows workspace platform in layers: reliable dock → reusable search → first-party widgets → profiles → controlled agents → a curated ecosystem.

Working name: Proton. Keep Proton Search as the name of the search experience. Product and repository renaming remain a separate decision; this plan does not rename identities, feeds, data folders or binaries.
